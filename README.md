# Maxinator

Каркас бота для MAX на `maxapi`.

## Запуск

1. Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установите проект в созданное окружение:

```bash
pip install -e .
```

Если нужны только зависимости без установки проекта как пакета:

```bash
pip install -r request.txt
```

3. Создайте `.env` по примеру `.env.example` и укажите токен:

```bash
cp .env.example .env
```

4. Запустите бота:

```bash
maxinator
```

## Что уже есть

- приветственное сообщение при старте диалога и по команде `/start`;
- inline-кнопка `Пройти тест`;
- после нажатия бот ждет следующее сообщение от пользователя как код теста;
- после получения кода бот только подтверждает получение, без дальнейшей логики.
